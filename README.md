# 山有小厨 · 餐厅网站

为沈阳沈河区「山有小厨」制作的一页式餐厅网站，包含一套可直接使用的在线预约流程。

## 预览

直接打开 `index.html` 即可浏览。为了让预约记录稳定保存在浏览器中，建议在项目目录启动一个本地静态服务器：

```bash
python -m http.server 8080
```

然后访问 <http://localhost:8080>。

已在 Chrome 下验证：桌面 1440px、移动端 390px，无横向溢出、无 JavaScript 运行错误。预览图见 `preview-desktop.jpg` 与 `preview-mobile.jpg`。

## 页面内容

- 首屏：门头实拍、营业状态、地址与地铁信息、预约入口
- 关于：小馆介绍与三个空间/做法关键词
- 菜单：辣椒炒肉、芝士猪排、温泉蛋蔬菜沙拉；金枪鱼炸虾 TACO 以深色字体卡片呈现（未提供实拍图，因此不使用不符的图片）；另附四道家常菜
- 空间：暖灯、木桌与热菜的氛围照片
- 预约：完整订座表单、日期/时段/人数选择、预约摘要、成功页
- 到店：地址、电话、营业时间、步行路线示意地图
- 我的预约：手机号查询、取消预约
- 移动端：全屏菜单、底部快捷预约栏

## 预约系统

- **日期**：今天起 30 天内；提供 7 天快捷日期，也可使用原生日期选择器选择更远日期。
- **时段**：11:30–20:00，每 30 分钟一个时段；当天已过或不足 30 分钟即将开始的时段自动隐藏。
- **容量**：每个时段 6 桌；1–4 人占 1 桌，5–8 人占 2 桌。满桌时段会显示“已满”并禁用。
- **人数**：1–8 人；9 人以上提示直接致电。
- **校验**：姓名 2–20 个字；中国大陆 11 位手机号；备注最多 80 字。
- **确认**：提交后生成预约号（如 `SY-1019-XXXX`），并支持下载 `.ics` 日历文件。
- **查询/取消**：在“我的预约”中输入预约手机号，可查看本机记录并取消未来预约。
- **防重复**：同一手机号、同一天、同一时段不能重复预约。
- **数据**：保存在浏览器 `localStorage` 中，仅限当前设备/浏览器；同一浏览器的多个标签页会同步刷新余位。

> 上线到真实餐厅时，需要将预约数据接到后端或云数据库，以便多设备共享桌位、店员收到通知并管理订单。前端已把读取、保存和容量判断集中在 `assets/js/app.js` 的 `loadReservations`、`saveReservations`、`getSlotInfo` 中，可替换为 API 调用。

## 配置

预约相关常量在 `assets/js/app.js` 顶部：

```js
const CONFIG = {
  openMinutes: 11 * 60 + 30,
  closeMinutes: 20 * 60 + 30,
  lastSlotMinutes: 20 * 60,
  slotStep: 30,
  leadMinutes: 30,
  tablesPerSlot: 6,
  maxParty: 8,
  daysAhead: 30,
  // ...
};
```

颜色、字体、间距等设计变量在 `assets/css/style.css` 的 `:root` 中。
